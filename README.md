# Jogo da Memória — HTML, CSS e JavaScript

Jogo da memória clássico em uma página, feito com **JavaScript puro e Bootstrap**, como exercício de treino para a WorldSkills (Web Technologies).

## Como jogar

Abra `index.html` no navegador, informe os dados iniciais e vá para `game.html`. Vire duas cartas por vez: se formarem par, ficam abertas; ao encontrar todos os pares, o botão **Novo Jogo** reinicia a partida.

## O que tem aqui

- `index.html` — tela inicial
- `game.html` — tabuleiro, lógica de virar cartas, verificação de pares e temporizador
- `bootstrap.css` — estilos base

Sem dependências e sem build.
